## 架构变更

### 双页面架构
```
App
├── Gallery 页（首页默认）
│   ├── 画作缩略图网格（50×50 缩略图）
│   ├── 新建画作按钮 → 设置宽高 → 进入 Editor
│   └── 点击画作 → 进入 Editor
└── Editor 页（原编辑器）
    ├── "← 返回" 按钮回到 Gallery
    └── 笔刷大小选择器（桌面侧栏 + 移动底部栏）
```

### 数据模型
```js
// 旧: state.canvasSize (正方形)
// 新: state.canvasWidth, state.canvasHeight (独立宽高)
//     state.brushSize (1-4，默认1)
//     state.currentPage ('gallery' | 'editor')

// 保存格式自动兼容旧数据
// 如果只有 canvasSize → width = height = canvasSize
```

### 快捷键表
| 键 | 功能 |
|----|------|
| P/E/F/I | 切换工具 |
| 1/2/3/4 | 笔刷大小 |
| [ / ] | 缩小/放大 |
| Ctrl+Z / Ctrl+Y | 撤销/重做 |
| Ctrl+S | 保存 |
| Ctrl+E | 导出 |
| Ctrl+N | 新建画布 |
| Esc | 返回画廊 |
| G | 网格开关 |
| Ctrl+滚轮 | 缩放画布 |
