# 像素绘画软件 — 设计规范

> 版本：v1.0 | 日期：2026-07-21

---

## 一、设计理念

**关键词**：温和、舒适、可爱、治愈

整体风格温暖柔和，像一间洒满阳光的小画室。圆角和柔阴影贯穿始终。像素黑猫作为吉祥物出现在加载画面中。

## 三、字体

| 平台 | 字体 | 备选 |

## 四、间距与圆角

| 元素 | 圆角 | 说明 |
|------|------|------|
| 按钮 | 8px | 温和的圆角 |
| 卡片/面板 | 12px | 柔和卡片 |
| 输入框 | 8px | |
| 色块 | 4px | 小圆角 |
| 模态框 | 16px | 更大的圆角 |

间距使用 4px 基准网格：4, 8, 12, 16, 20, 24, 32, 48

## 五、阴影

```css
/* 轻阴影 — 按钮、卡片 */
box-shadow: 0 2px 8px rgba(74, 48, 40, 0.1);

/* 中阴影 — 弹出层、模态框 */
box-shadow: 0 4px 16px rgba(74, 48, 40, 0.15);

/* 深阴影 — 很少使用 */
box-shadow: 0 8px 24px rgba(74, 48, 40, 0.2);
```

所有阴影使用深棕色（`#4A3028`）而非纯黑色，更柔和。

## 七、交互规范

- **按钮悬停**：颜色加深 10%，transition 0.2s
- **按钮点击**：轻微缩放（scale 0.96）
- **工具切换**：激活态显示暖色背景
- **Toast 提示**：顶部滑入，2 秒后自动消失
- **模态框**：从中心淡入，背景加半透明遮罩
- **存档卡片**：悬停微微上移（translateY -2px）
- **色块**：悬停放大 10%，点击有选中边框

## 八、加载动画

- 全屏暖米色背景 `#FFF8F0`
- 中央：像素黑猫逐帧奔跑
- 底部：轻柔的"加载中..."文字，带呼吸动画
- 猫的脚底：随机小像素点模拟尘土
- 加载完成后整体 fade out（0.6s）

## 九、响应式断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| 手机 | < 480px | 垂直堆叠，紧凑间距 |
| 平板 | 480px - 768px | 垂直堆叠，中等间距 |
| 桌面 | > 768px | 水平三栏布局 |
