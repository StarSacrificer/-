## 三、数据模型

```javascript
// 应用状态
const state = {
  // 画布
  pixels: [[]],          // 二维数组 [row][col]，存颜色值如 "#ff0000"
  canvasSize: 64,        // 画布尺寸
  currentColor: "#000000", // 当前选中颜色
  currentTool: "pen",    // pen | eraser | fill | picker

  // 视图
  zoom: 8,               // 缩放倍数（每像素占 N px）
  showGrid: true,        // 是否显示网格线

  // 历史（撤销/重做）
  history: [],           // 像素数据快照栈
  historyIndex: -1,      // 当前位置

  // 存档
  savedWorks: [],        // 本地存档列表
  currentWorkName: "",   // 当前作品名称

  // 语言
  lang: "zh",            // zh | en

  // 教程
  tutorialDone: false,   // 是否已完成新手教程
};

// 存档数据结构
{
  id: "1711567200000",     // 时间戳
  name: "我的像素画",       // 用户取名
  pixels: [[...], ...],    // 像素数据
  size: 64,                // 画布尺寸
  createdAt: "2026-07-21T12:00:00",
  updatedAt: "2026-07-21T14:30:00"
}
```

## 四、核心算法

### 4.1 画布渲染
遍历 state.pixels 二维数组，在 canvas 上绘制每个像素：
1. 先填充底色（白色或透明网格背景）
2. 绘制每个带颜色的像素
3. 如 showGrid 为 true，叠加网格线

### 4.2 泛洪填充（BFS）
以点击位置为起点，使用队列进行广度优先搜索：
- 检查相邻四方向的像素
- 颜色相同的入队并替换颜色
- 颜色不同或已替换的跳过
- 时间复杂度 O(n)，n 为填充区域像素数

### 4.3 撤销/重做
- 每次绘画操作结束时，将当前 pixels 深拷贝推入 history 栈
- historyIndex 指向当前状态
- 撤销：historyIndex-- 并恢复
- 重做：historyIndex++ 并恢复
- 新操作时清除 historyIndex 之后的所有快照
- 最多保留 50 个快照

### 4.4 坐标映射
将鼠标/触摸坐标转换为画布像素坐标：
```
pixelX = Math.floor((mouseX - canvasOffsetX) / zoom)
pixelY = Math.floor((mouseY - canvasOffsetY) / zoom)
```

### 4.5 图片导出
1. 创建隐藏的临时 canvas
2. 不绘制网格线
3. 以原始像素尺寸渲染（每像素 1×1）
4. 使用 canvas.toBlob() 导出 PNG
5. 创建 Blob URL，触发下载

## 五、事件处理

### 鼠标事件（桌面端）
- `mousedown` → 开始绘画
- `mousemove` → 持续绘画（在按下状态下）
- `mouseup` → 结束绘画，保存历史快照
- `mouseleave` → 同上

### 触摸事件（移动端）
- `touchstart` → 开始绘画（阻止默认滚动）
- `touchmove` → 持续绘画
- `touchend` → 结束绘画，保存历史快照

## 七、多语言实现

```javascript
const i18n = {
  zh: { save: "保存", export: "导出", /* ... */ },
  en: { save: "Save", export: "Export", /* ... */ },
};
// 统一取值函数
function t(key) { return i18n[state.lang][key] || key; }
```

所有 UI 文本通过 `t()` 函数取值。切换语言时更新 `state.lang`，然后调用 `updateAllTexts()` 刷新页面上的所有文本。

## 八、性能考虑

- 64×64 = 4096 个像素，渲染量很小，无性能问题
- 历史快照：每份约 16KB，50 份约 800KB，完全可接受
- localStorage 总空间约 5MB，足够存 20 幅画 + 历史
- 触摸事件使用 `passive: false` 防止移动端滚动卡顿
