# 像素绘画软件 — 开发步骤

> 版本：v1.0 | 日期：2026-07-21

---

## 开发原则

1. **小步推进**：每步只做一件事，做完可预览验证
2. **逐层叠加**：后一步基于前一步的稳定代码
3. **先骨架后血肉**：先建好 HTML/CSS 框架，再填充 JS 功能
4. **单个文件**：所有代码在一个 `pixel-art.html` 中

## 开发阶段

### 第一阶段：骨架搭建

#### 步骤 1：HTML 骨架 + CSS 主题
- [ ] 创建完整的 HTML 结构（顶栏、工具栏、画布区、调色板、底栏）
- [ ] 编写暖色调 CSS 主题（颜色、字体、圆角、阴影）
- [ ] 实现基础响应式布局（桌面三栏 / 移动端堆叠）
- [ ] 添加加载画面的 HTML 结构
- **产出**：打开页面看到完整的静态布局

#### 步骤 2：画布渲染
- [ ] 实现像素数据模型（二维数组初始化）
- [ ] 实现 Canvas 渲染函数（绘制像素 + 网格线）
- [ ] 画布自适应居中显示
- **产出**：看到 64×64 的网格画布

#### 步骤 3：画笔 + 橡皮
- [ ] 实现坐标映射（鼠标位置 → 像素坐标）
- [ ] 实现画笔工具（点击/拖拽涂色）
- [ ] 实现橡皮工具（点击/拖拽擦除）
- [ ] 鼠标事件绑定（mousedown/move/up/leave）
- **产出**：可以用鼠标在画布上画画和擦除

#### 步骤 4：调色盘

- [ ] 实现点击选色

#### 步骤 5：填充 + 取色器
