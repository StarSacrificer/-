# 像素绘画软件 — 产品需求文档

> 版本：v1.0 | 日期：2026-07-21 | 状态：MVP 开发中

---

## 一、产品概述

一款纯网页端的像素绘画应用，无需安装，电脑和手机浏览器打开即用。适合像素画初学者和爱好者。

## 二、目标用户

- 像素画入门学习者
- 喜欢像素艺术的普通人
- 需要一个轻量级像素画工具的用户

## 三、核心功能

### 3.1 像素画布
- 默认 64×64 像素画布
- 新建时可自定义尺寸（8~128）
- 显示/隐藏网格线
- 缩放：400% / 800% / 1600% 三档

### 3.2 绘画工具
| 工具 | 功能 |
|------|------|
| 画笔 | 点击或拖拽涂色 |
| 橡皮 | 点击或拖拽擦除（还原为白色） |
| 填充 | 泛洪填充，将相连同色区域替换为当前颜色 |
| 取色器 | 从画布上吸取颜色 |
| 撤销 | 回退到上一步（最多 50 步） |
| 重做 | 恢复已撤销的步骤 |

### 3.3 颜色系统
- 预设颜色色块（基础色 + 暖色系 + 自然色系）
- 浏览器原生取色器（支持任意颜色）

### 3.4 文件操作
- **导出**：将画布导出为 PNG 图片，下载到本地
- **保存**：将当前画保存到浏览器本地存储（localStorage）
- **加载**：从存档列表加载已保存的画继续编辑
- **删除**：删除不需要的存档
- **自动保存**：当前编辑中的画自动暂存，防止意外关闭丢失

### 3.5 新建画布
- 可自定义画布尺寸（默认 64，范围 8~128）
- 可选背景色（白色 / 透明）
- 新建前提示保存当前画

### 3.6 存档管理
- 最多保存 20 幅画
- 每条存档显示：缩略图、名称、日期
- 数据存储在浏览器 localStorage 中
- 界面提示用户：清除浏览器数据会导致存档丢失

### 3.7 加载动画
- 应用启动时显示全屏加载画面
- 像素黑猫奔跑动画（6~8 帧逐帧动画）
- 暖米色背景，猫脚底有小尘土粒子特效
- 加载完成后渐变消失

### 3.8 新手教程
- 首次使用时自动弹出引导教程
- 逐步介绍各个工具和功能
- 用户可跳过，也可在菜单中重新打开

### 3.9 多语言
- 支持简体中文（默认）和 English
- 顶部导航栏提供语言切换按钮
- 所有 UI 文本、提示、教程均可切换

---

## 四、非功能需求

- **跨平台**：桌面端和移动端浏览器均可使用
- **无需安装**：纯网页，打开即用
- **响应式**：自适应不同屏幕尺寸
- **离线可用**：加载完成后，无网络也能使用（静态资源）
- **温和舒适**：暖色调 UI，柔和圆角，舒适间距

## 五、约束条件

- 纯前端，无后端服务
- 所有数据存于用户浏览器
- 单个 HTML 文件（方便分享和管理）
- 无需构建工具，无需 Node.js
